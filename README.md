# Triple Decoisohedron Stack EID Prototype

Center:
- EID tensor loop

Stack:
- min shell
- med shell
- high shell

Each shell:
- 20 vectors
- 12 truth tensors
- 8 shadow tensors

The shell is modeled as a custom 20-vector icosahedral-style shell.
